# Security Policy

## Supported versions

Security fixes are applied to `main` and the latest published release. Older
tags are not supported unless a release note says otherwise.

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue, discussion,
pull request, log, screenshot, or chat message.

Use the private **Report a vulnerability** action on the repository's
**Security → Advisories** page. Include the affected commit or release, a
minimal reproduction, the expected and observed impact, and any suggested
mitigation. Remove credentials, private keys, personal data, and live network
endpoints from the report.

If private vulnerability reporting is temporarily unavailable, contact the
repository owner through GitHub and request a private channel before sharing
technical details.

We will acknowledge a report as soon as practical, investigate it privately,
and coordinate disclosure after a fix or mitigation is available.
